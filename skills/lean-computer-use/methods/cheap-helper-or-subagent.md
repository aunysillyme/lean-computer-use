# Choose the app worker

The main session frames the task, supplies the packet, verifies the saved evidence and reports.
It never drives the screen.

If you already have a suitable cheap helper, give it the same bounded brief and desk commands.
Its capabilities and data handling must fit the user's granted scope.
Use `desk-runner` when no helper is available, when a helper fails, or when a fresh host subagent is the clearer fit.
The method works with the runner alone.

Keep model choice and service setup in your host configuration.
This package installs a Claude Code runner definition and plain Markdown methods; it creates no external model account.
Confirm the worker can call the desk scripts before assigning the app job.
If the worker cannot return saved evidence, report the limitation and keep verification with the main session.

Use one worker for jobs that share an app window.
Send the whole predictable action chain and all read-back fields together.
Do not split a single app's actions among concurrent workers.
