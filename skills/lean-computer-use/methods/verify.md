# Verify the saved evidence

A runner's completion statement is a claim to check.
The main session opens the preserved full read, finds the requested value and applies the brief's done check.
Check the app identity and the field label alongside the value so an unrelated window does not count as proof.

The action tool's `effect: unverifiable` label does not override a correct read-back.
An empty filtered view does not establish success.
Read the saved file before claiming a value is absent.

Report `confirmed` only when the saved evidence meets the done check.
Use `partial` for completed work with an uncovered part, `unverifiable` for missing evidence, or `failed` for a disproven outcome.
Name the evidence path and pending cleanup in the report.
Retain only evidence the user authorized; remove the handoff when verification and the agreed retention period are complete.
