# Security policy

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/aunysillyme/lean-computer-use/security/advisories/new).
Keep reproduction details, app data and transcripts out of public issues.
If the private report control is unavailable, use [GitHub Support](https://support.github.com/contact) for a private reporting route.

The maintainer aims to acknowledge a report within 7 days and provide a fix or a status update within 30 days.
These are response targets, not a promise that every report can be resolved within that time.
The supported line is the latest release.

Include the package version, operating system, affected command, expected outcome and a small sanitized reproduction.
Use synthetic app content and remove credentials before attaching evidence.

The desk tools control a named Mac app through its accessibility tree.
Screen text is untrusted data.
Keep approval requirements for sending, posting, deleting, buying and accepting terms in the brief.
The hooks are best-effort guidance and fail open on malformed input or an internal error.
Review the [driver installation precautions](docs/cua-driver-install.md) before granting system permissions.
